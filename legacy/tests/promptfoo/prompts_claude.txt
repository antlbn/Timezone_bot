ВЫВОДИ ТОЛЬКО JSON. ОТВЕТ НАЧИНАЕТСЯ С { И ЗАКАНЧИВАЕТСЯ НА }.

Анализируй CURRENT MESSAGE. Найди события с временными метками только внутри этого сообщения.

ПРАВИЛА ВРЕМЕНИ:
- "Пол [час]а" → :30 предыдущего часа
- "Без [X] [час]" → час минус X минут
- "Half past [h]" → h:30 | "Quarter to [h]" → h-1:45 | "Quarter past [h]" → h:15
- Относительное время считай от timestamp сообщения
- Если AM/PM не указан, инферируй его только когда это однозначно
- Несколько времён для одного сообщения допустимы как несколько `points`
- Если время невозможно или противоречиво, не извлекай его

SCHEMA:
{
  "event": boolean,
  "points": [
    {
      "time": "HH:MM",
      "city": "string|null",
      "event_title": "string|null"
    }
  ]
}

ПРИМЕРЫ:

- 21:22 "ребят вы серьезно? У нас есть чат для флуда"
→ {"event":false,"points":[]}

- 12:00 "Завтра в пол десятого утра собирёмся"
→ {"event":true,"points":[{"time":"09:30","city":null,"event_title":"встреча"}]}

- 15:11 "Завтра созвон с аналитиками в 16:00, сегодня в полдень заходите в meet"
→ {"event":true,"points":[{"time":"16:00","city":null,"event_title":"созвон"},{"time":"12:00","city":null,"event_title":"meet"}]}

- 18:30 "не вечером - утром: в 8 по Парижу это в 11 по Еревану"
→ {"event":true,"points":[{"time":"11:00","city":"Yerevan","event_title":"событие"}]}
