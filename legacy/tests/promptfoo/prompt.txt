### ВНИМАНИЕ: ВЫВОДИ ТОЛЬКО JSON. НИКАКИХ ПОЯСНЕНИЙ. ОТВЕТ ДОЛЖЕН НАЧИНАТЬСЯ С { И ЗАКАНЧИВАТЬСЯ НА }.

Твоя задача — анализировать только CURRENT MESSAGE. Определи, есть ли координация события со временем, и извлеки только однозначные time points.

ИНСТРУКЦИЯ ДЛЯ ОТВЕТА (JSON SCHEMA):
{
  "event": boolean,
  "points": [
    {
      "time": "HH:MM",
      "city": "string|null",
      "event_title": "string|null"
    }
  ]
}

ПРАВИЛА:
- Все времена в 24ч формате `HH:MM`
- Относительное время считай от `CURRENT TIME (UTC)`
- Идиомы вроде `пол десятого`, `без пятнадцати восемь`, `halb zehn`, `9 y media` интерпретируй корректно
- `Утром` / `вечером` помогают с AM/PM, но сами по себе не создают `time`
- Невалидные сочетания (`14 pm`, `13 ночи`) не извлекай
- Номера подъезда, дома, этажа, задачи не должны становиться временем
- Если автор исправляет время, бери исправленное
- Если в одном сообщении несколько независимых моментов, верни несколько `points`
- Если `event=false`, верни `points=[]`

ПРИМЕРЫ:

Пример 0:
CURRENT TIME (UTC): 2026-03-13T12:00:00Z
CURRENT MESSAGE:
Завтра в пол десятого утра собирёмся
Output:
{"event":true,"points":[{"time":"09:30","city":null,"event_title":"встреча"}]}

Пример 1:
CURRENT TIME (UTC): 2026-03-13T16:40:00Z
CURRENT MESSAGE:
встречаемся у 9го подъезда в 18
Output:
{"event":true,"points":[{"time":"18:00","city":null,"event_title":"встреча"}]}

Пример 2:
CURRENT TIME (UTC): 2026-03-13T21:22:00Z
CURRENT MESSAGE:
ребят вы серьезно? У нас есть чат для флуда
Output:
{"event":false,"points":[]}

Пример 3:
CURRENT TIME (UTC): 2026-03-13T15:11:00Z
CURRENT MESSAGE:
Завтра созвон с аналитиками в 16:00, сегодня в полдень заходите в meet
Output:
{"event":true,"points":[{"time":"16:00","city":null,"event_title":"созвон с аналитиками"},{"time":"12:00","city":null,"event_title":"meet"}]}

Пример 4:
CURRENT TIME (UTC): 2026-03-13T12:21:00Z
CURRENT MESSAGE:
через час будет созвон
Output:
{"event":true,"points":[{"time":"13:21","city":null,"event_title":"созвон"}]}

Пример 5:
CURRENT TIME (UTC): 2026-03-13T15:30:00Z
CURRENT MESSAGE:
подтвердилось, сегодня до 8 нужно отправить коммюнике
Output:
{"event":true,"points":[{"time":"20:00","city":null,"event_title":"дедлайн"}]}
