ВЫВОДИ ТОЛЬКО JSON. ОТВЕТ НАЧИНАЕТСЯ С { И ЗАКАНЧИВАЕТСЯ НА }.
БЕЗ ЛИШНЕГО ТЕКСТА И ПОЯСНЕНИЙ.

ЗАДАЧА:
Проанализируй CURRENT MESSAGE.
Цель: определить, содержит ли сообщение координацию события со временем, и извлечь только однозначные time points.

ИНСТРУКЦИИ:
1. Выводи время строго в 24-часовом формате `HH:MM`.
2. Инферируй AM/PM только если это действительно однозначно из формулировки и текущего времени.
3. Учитывай языковые идиомы: `пол восьмого`, `без пятнадцати восемь`, `halb zehn`, `9 y media`.
4. Относительное время (`через 20 минут`) вычисляй от CURRENT TIME (UTC).
5. Используй массив `points`; каждый объект содержит `time`, `city`, `event_title`.
6. Если в одном сообщении есть окно или два разных события, верни несколько `points`.
7. Если время невозможно или противоречиво (`13 ночи`, `14 pm`), не извлекай его.
8. Если `event=false`, верни `points=[]`.

JSON SCHEMA:
{
  "event": boolean,
  "points": [
    {
      "time": "HH:MM",
      "city": "string|null",
      "event_title": "string|null"
    }
  ]
}

ПРИМЕРЫ:

Пример 1 — встреча с идиомой:
CURRENT TIME (UTC): 2026-03-13T12:00:00Z
CURRENT MESSAGE:
Ок, тогда встречаемся без пятнадцати восемь у входа
→ {"event":true,"points":[{"time":"19:45","city":null,"event_title":"встреча"}]}

Пример 2 — явный город:
CURRENT TIME (UTC): 2026-03-13T18:30:00Z
CURRENT MESSAGE:
не вечером - утром: в 8 по Парижу это в 11 по Еревану
→ {"event":true,"points":[{"time":"11:00","city":"Yerevan","event_title":"встреча"}]}

Пример 3 — флуд:
CURRENT TIME (UTC): 2026-03-13T21:22:00Z
CURRENT MESSAGE:
ребят вы серьезно? У нас есть чат для флуда
→ {"event":false,"points":[]}
