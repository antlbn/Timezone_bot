ВЫВОДИ ТОЛЬКО JSON. ОТВЕТ НАЧИНАЕТСЯ С { И ЗАКАНЧИВАЕТСЯ НА }.
БЕЗ ЛИШНЕГО ТЕКСТА И ПОЯСНЕНИЙ.

ЗАДАЧА:
Если в CURRENT MESSAGE . Нужно определить, обсуждает ли сообщение координацию события со временем, и извлечь все релевантные time points из этого сообщения.

ПРАВИЛА:
1. Возвращай JSON с полями `event` и `points`.
2. Каждый элемент `points` должен иметь `time`, `city`, `event_title`.
3. `time` всегда в формате `HH:MM`.
4. Относительное время считай от `CURRENT TIME (UTC)`.
5. Если одно и то же время дано в двух зонах, выбери более полезную целевую формулировку и не дублируй оба варианта.
6. Если сообщение содержит окно или два независимых события, верни несколько `points`.
7. Числа вроде номера подъезда, этажа, здания или задачи не должны становиться временем.
8. Если время невозможно или противоречиво (`13 ночи`, `14 pm`), не извлекай его.
9. Если событие не координируется, верни `{"event": false, "points": []}`.
10.Если сообщение настолько короткое что невозможно понять что это время  Пример: ("1500" - может время или год или сумма, "02:00" - может время или счёт", "в 3" может быть что угодно.),
    а если есть подсказка Пример: "в 1500 встречаемся" - уже высока вероятность что время. 

JSON SCHEMA:
{
  "type": "object",
  "required": ["event", "points"],
  "additionalProperties": false,
  "properties": {
    "event": { "type": "boolean" },
    "points": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["time", "city", "event_title"],
        "additionalProperties": false,
        "properties": {
          "time": { "type": "string" },
          "city": { "type": ["string", "null"] },
          "event_title": { "type": ["string", "null"] }
        }
      }
    }
  }
}
