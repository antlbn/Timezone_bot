ВЫВОДИ ТОЛЬКО JSON. ОТВЕТ НАЧИНАЕТСЯ С { И ЗАКАНЧИВАЕТСЯ НА }.

Анализируй CURRENT MESSAGE. Найди будущие или текущие события с временными метками: звонки, встречи, дедлайны, договорённости.

ПРАВИЛА ВРЕМЕНИ (24ч формат):
- «Пол [час]а» → :30 предыдущего часа (пол восьмого = 07:30 или 19:30)
- «Без [X] [час]» → час минус X минут (без пятнадцати восемь = 07:45 или 19:45)
- «[X] минут [час]ого» → предыдущий час + X минут (двадцать минут шестого = 05:20)
- «Half past [h]» → h:30 | «Quarter to [h]» → (h-1):45 | «Quarter past [h]» → h:15
- «halb [h]» (нем.) → (h-1):30 | «[h] y media» (исп.) → h:30 | «[h]h» (фр.) → h:00
- Относительное время считай от timestamp сообщения («через час» от 12:21 = 13:21)
- Если AM/PM не указан, инферируй его только когда это действительно однозначно
- «После обеда» / «утром» / «вечером» без числа сами по себе не становятся `time`
- Если время невозможно или противоречиво (`13 ночи`, `14 pm`), не извлекай его

ПРАВИЛА СМЫСЛА:
- Сначала проверь, что число не является номером подъезда, этажа, задачи или здания
- Если автор явно исправляет время, бери исправленное и игнорируй отменённое
- Если в одном сообщении есть два независимых события или временное окно, верни несколько `points`
- Если один и тот же момент указан в двух зонах, выбери более полезную целевую формулировку, а не дублируй обе

SCHEMA:
{
  "event": boolean,
  "points": [
    {
      "time": "HH:MM",
      "city": "string|null",
      "event_title": "string|null"
    }
  ]
}

ПРИМЕРЫ:

- 21:22 "ребят вы серьезно? У нас есть чат для флуда"
→ {"event":false,"points":[]}

- 12:00 "Завтра в пол десятого утра собирёмся"
→ {"event":true,"points":[{"time":"09:30","city":null,"event_title":"встреча"}]}

- 16:40 "встречаемся у 9го подъезда в 18"
→ {"event":true,"points":[{"time":"18:00","city":null,"event_title":"встреча"}]}

→ {"event":true,"points":[{"time":"16:00","city":null,"event_title":"созвон с аналитиками"},{"time":"12:00","city":null,"event_title":"meet"}]}

→ {"event":true,"points":[{"time":"11:00","city":"Yerevan","event_title":"событие"}]}
