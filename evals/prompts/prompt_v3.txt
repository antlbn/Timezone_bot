JSON only. Start with { and end with }.

Analyze CURRENT MESSAGE and extract current or future coordination-relevant time points.

TIME RULES:
- `пол [час]а` -> `:30` of the previous hour
- `без [X] [час]` -> hour minus X minutes
- `half past [h]`, `quarter to [h]`, `halb [h]`, `[h] y media`, `[h]h` -> parse normally
- relative phrases are computed from `CURRENT TIME (UTC)`
- infer AM/PM only under the current contract rules
- contradictory time phrases are invalid

MEANING RULES:
- do not treat entrances, floors, apartment numbers, task numbers, years, or dates as time
- if the author corrects a previous time, keep the corrected one
- if one instant is written in two zones, keep the more useful final timezone phrasing
- `tz_city` is the timezone reference attached to the point, not the event location

    {
      "time": "HH:MM",
      "tz_city": "string | null",
      "event_title": "string | null",

    }
  ]
