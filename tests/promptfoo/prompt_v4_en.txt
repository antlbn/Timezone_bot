TASK: find any specific time mention in the message (hours/minutes). Return JSON.

=== STEP 1. IS THERE A TIME? ===
Look for a time-of-day reference:
  YES: "at 17:00", "at 9am", "14.30", "1500", "in an hour"
  NO: only a day reference ("tomorrow", "on Sunday") without an hour
  NO: a number that is not time ("entrance 9", "3rd floor")
  NO: a bot mention ("<@...>")

Colloquial formats:
  Russian: "пол-десятого утра" = 09:30 | "без пятнадцати восемь вечера" = 19:45
  Russian without a marker: "без пятнадцати восемь" = 07:45
  Russian: "двадцать минут шестого" = 05:20
  English: "half past 9 am" = 09:30 | "quarter to 8 in the evening" = 19:45
  German: "halb zehn" = 09:30 (NOT 10:30)
  Spanish: "9 y media" = 09:30 | French: "9h" = 09:00

Relative time: calculate from CURRENT TIME (UTC).

If there is no time:
{"time_mentioned": false, "points": []}

=== STEP 2. IS THE TIME VALID? ===
Discard impossible combinations:
  invalid: "13 at night" ("night" means 00:00-04:59)
  invalid: "14 pm" (PM = 1-12)
  invalid: "13 after midnight"

If invalid:
{"time_mentioned": false, "points": []}

=== STEP 3. AM OR PM? (am_pm_clear) ===
Set am_pm_clear = true when:
  yes: hour > 12 (17:00, 23:59)
  yes: 4 digits in a row (1500 = 15:00)
  yes: HH:MM with ":" or "." means 24-hour format
  yes: explicit marker such as "am/pm", "morning/evening/afternoon", "after lunch", "tonight", "matin", "morgens", "утра", "вечера", "дня"
  yes: relative time after exact calculation
  yes: "today at X" where one version is already in the past -> choose the future one

Edge case:  
  yes: bare hour where only ONE version is inside working hours (06:00-22:00):
    hour 1-5 -> choose PM (1 -> 13:00, 3 -> 15:00)
    hour 11-12 -> choose AM (11 -> 11:00, 12 -> 12:00)
  
Set am_pm_clear = false when:
  no: bare hour 6-10 without a marker, when both versions are inside working hours
  then return the AM version: "at 8" -> "08:00"

=== STEP 4. EXTRA RULES ===
- Correction: "not at 10, but at 11" -> take 11 and ignore 10
- Two zones: "at 3 Moscow time, that is 4 in Vienna" -> one time only, take the LAST one
- Multiple events -> return multiple points
- Ordinals (9th, 3rd) plus a noun (entrance, floor, apartment) -> not time
- tz_city = the city/timezone the time refers to ("at 7pm Berlin time" -> tz_city="Berlin"), NOT the event location
