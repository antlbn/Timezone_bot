# 00. Architecture (C4 & Hexagonal)

This document describes the bot architecture using the C4 model projected onto Hexagonal Architecture (Ports and Adapters).

## 1. System Context (Level 1)
Interaction of the bot with the outside world.

```mermaid
flowchart TD
    User([Chat User])
    System[Timezone Bot]
    LLM[LLM Provider\nGroq / Gemini]
    
    User -- "Sends messages via messengers" --> System
    System -- "Detects time mentions via" --> LLM
```

## 2. Container Diagram (Level 2)
Internal system containers and transport.

```mermaid
flowchart TD
    User([Chat User])
    LLM[LLM API]
    
    subgraph "Timezone Bot System"
        Telegram[Telegram Adapter\naiogram]
        Discord[Discord Adapter\ndiscord.py]
        Core[Hexagonal Core\nBusiness Logic]

    end
    
    User -- "Telegram API" --> Telegram
    User -- "Discord API" --> Discord
    
    Telegram -- "InputData" --> Core
    Discord -- "InputData" --> Core
    
    Core -- "Read/Write" --> SQLite
    Core -- "Read/Write" --> Mem
    Core -- "Prompt/Parse" --> LLM
```

## 3. Component Diagram (Level 3 - Core)
Internal structure of the Hexagonal Architecture.

```mermaid
flowchart LR
    Inbound[Inbound Adapters\nTG / Discord]
    Outbound[Outbound Adapters\nSQLite, LLM, TG/DS Exec]
    
    subgraph Core ["Hexagonal Core (Domain)"]
        direction TB
        Pipeline[Message Pipeline\nGuard -> ... -> Decision]
        Services[Use Cases\nOnboarding, Processing]
        Ports[Outbound Ports\nInterfaces]
        
        Pipeline --> Ports
        Services --> Ports
    end
    
    Inbound -- "Calls Services" --> Services
    Inbound -- "Passes Context" --> Pipeline
    Ports -. "Implemented by" .-> Outbound
```

**Key Layer Rules:**
- **Core:** Pure business logic, framework-agnostic. Contains only pure functions, pipelines, and dataclasses.
- **Ports:** Strict interfaces (abstract classes) for DB, LLM, system time, and message delivery.
- **Adapters:** Port implementations that perform actual network or disk I/O.
